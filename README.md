
# **iVolve DevOps Training Repository**  

## **Overview**  
This repository documents my DevOps training journey at iVolve, covering various tools and technologies essential for modern DevOps workflows. The training includes hands-on practice and project-based learning in the following areas:  

## **Training Modules**  

### **1. Linux**  
- Fundamentals of Linux  
- Shell scripting  
- User and permission management  

### **2. AWS**  
- EC2, S3, IAM, and networking  
- Infrastructure as a Service (IaaS) concepts  
- Hands-on practice with cloud resources  

### **3. Ansible**  
- Configuration management  
- Writing and executing Ansible playbooks  
- Role-based automation  

### **4. Terraform**  
- Infrastructure as Code (IaC)  
- Writing Terraform configurations  
- Deploying AWS resources with Terraform  

### **5. Jenkins**  
- CI/CD pipeline setup  
- Automating builds and deployments  
- Integration with Docker and Kubernetes  

### **6. Kubernetes**  
- Container orchestration  
- Deploying applications on Kubernetes  
- Managing clusters and workloads  

## **Final Project: CloudDevOpsProject**  
The training concludes with a final project, **CloudDevOpsProject**, integrating all learned technologies into a real-world DevOps workflow.  

🔗 **Project Repository:** [CloudDevOpsProject](https://github.com/Doaa-hemaid/CloudDevOpsProject.git)
